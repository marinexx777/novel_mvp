---
chapter: 31
title: "— LES BARRIÈRES S’OUVRENT"
---
Les restrictions furent levées par étapes.

Le premier matin où les déplacements familiaux furent de nouveau autorisés, les routes se remplirent avant l’aube.

Julien et Camille attendirent trois jours.

Ils nettoyèrent la voiture. Remirent dans le coffre les cadeaux qui dormaient depuis décembre. Ajoutèrent quelques paquets commandés pendant le confinement.

Dans l’entrée, Julien regarda la feuille jaunie.

Laver les mains.

Désinfecter les clés.

Jeter les masques correctement.

RENTRE À LA MAISON.

La peur n’a pas le droit de vote.

Il décrocha les trois premières lignes.

Camille l’arrêta avant qu’il retire les deux dernières.

— Laisse-les.

— Pour toujours ?

— Peut-être.

Julien recolla un coin qui se détachait.

Puis ils descendirent les valises.
